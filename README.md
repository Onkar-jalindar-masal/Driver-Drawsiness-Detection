# Driver Drawsiness Detection

Driver Drowsiness Detection is a computer vision-based safety system designed to detect driver fatigue and prevent accidents caused by drowsy driving. The system uses a webcam to monitor the driver's eye movements in real time and calculates the Eye Aspect Ratio (EAR) using MediaPipe Face Mesh facial landmarks. When the driver's eyes remain closed for a certain number of frames, the system identifies signs of drowsiness and triggers an audio alarm to alert the driver.
